3. Bulk import names each skipped file and says why in plain words.
4. "1 piece added" instead of "1 pieces added".
5. One counting helper: "1 file", "1 attachment", "1 work" everywhere a number meets a noun.
6. Removing a logged session says "Remove this session".
7. Delete and Remove buttons say what they act on (this call, this contact, this time, this question).
8. Number boxes read "$1,200", "12,5" and "16 in" correctly instead of saving zero.
9. Dates follow the phone's own order with the weekday first ("Tue, Dec 22, 2026" in the US).
10. Money in the app has thousands separators ($1,300.00).
